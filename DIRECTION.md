# Gitrew landing direction

Brief: retain the existing Nuxt UI / Primer character while renaming the product and explaining GitHub first. Visitors must understand team conversation tied to code, see what exists today, and compare Gitea/GitLab plans. The requested provider row opens an explanatory panel below it. No paid imagery.

Concept: Gitrew is the meeting place beside the repository.

Explored directions: a cool-white repository companion (selected), a dark operations console, and a warm editorial workshop. The console makes the roadmap feel already operational; the workshop drifts from the actual application. The selected direction keeps the product recognizable and its status legible.

Tokens: system UI font deliberately matches the Primer-based application; neutral ink / muted gray / cool white with green reserved for the main action. Dark mode follows existing semantic application tokens. 12px status labels, 15px reading text, 20–36px section headings, 46–76px hero. Constrained 1240px layout, 40px desktop / 22px phone gutters.

Signature: Git providers share one row; clicking changes the explanation below it, with a brief transition and a reduced-motion fallback. Status labels distinguish current GitHub chat from planned providers and agent handoffs. Card grids and decorative gradients are refused; product illustration is clearly labelled illustrative.

Must keep: existing brand mark, sign-in, deployment paths, source link, light/dark theme. New copy and provider comparison are the core redesign. Technical coverage is reported in CRITIQUE.md; desktop and phone renders are in ignored artifacts/design.
